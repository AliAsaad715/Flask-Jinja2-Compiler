# Flask-Jinja2 Compiler

مترجم مصغر يحلل Python وJinja2 وHTML وCSS، ويبني أشجار AST وجداول الرموز، وينفذ التحليل الدلالي، ثم يولد موقع HTML ثابتاً مترابطاً.

## التشغيل السريع

من PowerShell داخل مجلد المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_project.ps1
```

ينفذ الأمر المراحل التالية:

1. ترجمة مصادر Java.
2. تحليل ملف Python والقوالب وCSS.
3. طباعة AST وجداول الرموز وتدفق البيانات.
4. إيقاف التوليد عند وجود خطأ نحوي أو دلالي.
5. توليد الموقع داخل `generated/static_site`.
6. التحقق من خلو HTML النهائي من Jinja ومن سلامة الروابط المحلية.

بعد نجاح الأمر افتح:

```text
generated/static_site/index.html
```

## تعديل المنتجات

البيانات موجودة في مصفوفة `products` داخل `Tests/app_py.txt`. بعد إضافة منتج أو حذفه أو تعديله، أعد تشغيل `run_project.ps1`. ينشئ المولد تلقائياً صفحة تفاصيل وصفحة حذف لكل منتج ويحدّث روابط القائمة.

لشرح التصميم الكامل ونتائج الاختبارات راجع `REPORT.md`.
